Work with us

Hard.Money is a small, remote, independent publisher. We pay for expertise and ship fast. Most roles are freelance or part-time to start.

Finance Writer — Private Lending

Freelance · Remote · $0.25–$0.50/word

Write 1,500–2,500 word guides with worked examples. You have originated, brokered or closed hard money loans, or have written for a top-tier finance publication.

Lender Underwriter (Content Reviewer)

Freelance · Remote · $150–$300/review

Fact-check guides and rate tables against current practice. Active or recent underwriting experience at a private lender required.

Real Estate Attorney (State Guides)

Freelance · Remote · Per-guide fee

Review state licensing, usury and foreclosure summaries for accuracy. Licensed in one or more of: TX, FL, CA, GA, AZ, NC, OH, NY.

Video Editor / Explainer Producer

Freelance · Remote · Per-video

Turn scripts and calculator walkthroughs into 4–8 minute explainers. Portfolio of finance or education content preferred.

Data Researcher — Lender Directory

Part-time · Remote · Hourly

Verify lender terms, licenses and contact details quarterly; maintain the directory dataset. Detail-obsessed; comfortable with spreadsheets and public records.

Front-End Developer (Static Sites)

Freelance · Remote · Project

Build calculators and interactive tools in vanilla JS; performance and accessibility first. Familiarity with static hosting and GitHub Pages.

How we work

  • Async, written-first, remote. Weekly check-in.
